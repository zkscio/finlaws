## 使い方

1. **まず `INDEX.md` を見る** — 全法令の章一覧
2. **読みたい章だけ開く** — 例: `01_資金決済法/04_第三章の二_電子決済手段等.md`
3. **条文番号で検索** — 例: `grep -rn "第2条" 01_資金決済法/`
4. **全文が必要なときだけ** — `01_資金決済法.md`（分割前の原文）

各ファイルは章/節/款単位に分割されています。1ファイルが AI のコンテキスト窓に収まるサイズです。

## 条文の追加・更新手順（メンテナ向け）

1. **e-Gov から条文全文を取得**し、BOM付きUTF-8 で保存
   - ファイル名: `NN_法令名.md`（NN は連番）
2. **分割スクリプトを実行**（1法令だけ指定）
   ```
   python3 scripts/laws_splitter.py NN_法令名.md
   ```
3. 自動で以下が生成されます
   - `NN_法令名/` （章/節/款/附則に分割）
   - `INDEX.md` （マスターINDEX更新）

分割スクリプトは形式A（`## 第X章`）・形式B（行頭 `第X章　…`）・編（`## 第X編`）に対応しています。大きな章（1200行以上）は自動で節/款まで再分割し、章見出しのない小型法令は `01_本則.md` にまとめます。
