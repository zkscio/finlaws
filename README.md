# ⚖️ finlaws — 金融業界関連法令の条文全文リポジトリ

> **日本の金融業界関連法令**（法律・政令・府省令・内閣府令・命令・規則）の条文全文を、
> e-Gov 法令検索（https://laws.e-gov.go.jp/）から取得し、Markdown化した一次資料庫です。

## 📊 概要

- **収録**: 金融業界関連法令 **473件**（e-Gov 現在施行版）
- **形式**: Markdown・**BOM付きUTF-8**（日本語表示崩れ防止）
- **出典**: [e-Gov 法令検索](https://laws.e-gov.go.jp/) の「現在施行」版
- **取得日**: 2026-08-14
- **構成**: 各法令フォルダ = `00_全文.md`（条文全文）+ 章分割 + `_INDEX.md`（章一覧）
- **AI利用最適化**: 全文を章単位に分割し、1ファイルがコンテキスト窓に収まるサイズ

> ⚠️ 条文は改正・施行状況により変わります。最新・正本は必ず [e-Gov 法令検索](https://laws.e-gov.go.jp/) を参照してください。

## 🚀 AI・検索での使い方

**前提**: リポジトリをクローンまたはローカルに配置。

```bash
git clone https://github.com/zkscio/finlaws.git
```

### 1. 法令を探す
- **法令一覧**: `INDEX.md` 冒頭の「法令一覧（全473件）」テーブル（法令名・種別・law_id・フォルダ）
- **章一覧**: `INDEX.md` の「章分割インデックス」セクション

### 2. 条文を引く（コマンドライン検索）
```bash
# 条文番号で検索（例: 資金決済法 第2条）
grep -rn "第2条" 01_資金決済法/

# キーワードで全法令横断検索
grep -rn "電子決済手段" .

# 特定法令フォルダ内の全文
cat 01_資金決済法/00_全文.md
```

### 3. AI（LLM）での参照
- **全文が必要**: `NN_法令名/00_全文.md`（分割前の原文）
- **章だけ必要**: `NN_法令名/NN_章_名称.md`（コンテキスト窓に収まる）
- **構造把握**: `NN_法令名/_INDEX.md`（その法令の章一覧）
