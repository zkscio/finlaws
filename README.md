## 使い方（AI向け）

1. **まず INDEX を見る** → `laws/INDEX.md`（全法令の章一覧）
2. **読みたい章だけ開く** → 例: `laws/01_資金決済法/04_第三章の二_電子決済手段等.md`
3. **条文番号で検索** → `grep -rn "第2条" laws/01_資金決済法/`
4. **全文が必要なときだけ** → `laws/01_資金決済法.md`（分割前の原文、残置）

各ファイルは章/節/款単位に分割済み。1ファイルが AI のコンテキスト窓に収まるサイズ。

## 新法令の追加手順

```bash
# 1) e-Gov から条文全文を取得し、BOM付きUTF-8 で保存
#    ファイル名: NN_法令名.md （NNは連番）
#    例: /opt/data/laws/22_金融サービスの提供及び利用環境の整備等に関する法律.md

# 2) 分割スクリプトを実行（その1法令だけ）
python3 /opt/data/scripts/laws_splitter.py 22_法令名.md

# 3) 自動で以下が生成される:
#    - laws/22_法令名/  （章/節/款/附則に分割）
#    - laws/INDEX.md    （マスターINDEX更新）
```

分割スクリプトは形式A（`## 第X章`）・形式B（行頭 `第X章　…`）・編（`## 第X編`）に対応。
大きな章（1200行以上）は自動で節/款まで再分割する。章見出しがない小型法令は `01_本則.md` にまとめる。

## e-Gov からの新規取得（全文）

e-Gov は SPA のため curl では本文が取れない。web_extract（Firecrawl）で取得し、`cache/web/` に全文が保存される。その後 `scripts/extract_laws_cache.py` で本文を抽出して `laws/` に整形する。

## 再生成（全法令）

```bash
python3 /opt/data/scripts/laws_splitter.py
```
