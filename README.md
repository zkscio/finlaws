## 📋 概要

- **収録**: 日本の金融関連法令 **56本**（法律・政令・府省令）

## 🚀 クイックスタート

クローンしてすぐ使えます。

```bash
git clone https://github.com/zkscio/finlaws.git
cd finlaws
```

**読み方（3ステップ）**

1. **全体を把握** → [`INDEX.md`](INDEX.md)（全法令の章一覧）
2. **法令を開く** → `01_資金決済法/` などのフォルダ
3. **条文を検索** → コマンドラインで:

```bash
# 条文番号で検索
grep -rn "第2条" 01_資金決済法/

# キーワードで全法令横断検索
grep -rn "電子決済手段" .
```

## 📂 ディレクトリ構造

```
finlaws/
├── INDEX.md                          # マスターインデックス（全法令の章一覧）
├── README.md                         # このファイル
├── LICENSE                           # ライセンス
├── 01_資金決済法/                    # 各法令フォルダ
│   ├── 00_全文.md                    # 分割前の条文全文（原文）
│   ├── 00_序章・目次.md              # 序章・目次
│   ├── 01_第一章_総則.md            # 章分割ファイル
│   ├── ...
│   ├── 99_附則.md
│   └── _INDEX.md                     # その法令の章一覧
├── 02_犯罪収益移転防止法/
├── 03_銀行法/
├── ...
└── 56_商品投資に係る事業の規制に関する法律/
```

各法令フォルダ内の **`_INDEX.md`** に、その法令の章構成一覧があります。

## ✨ 分割ポリシー

- 各法令を **章/節/款/附則** 単位に自動分割
- 大きな章（1200行以上）は節/款まで再分割
- 章見出しのない小型法令は `01_本則.md` にまとめる
- 分割前の全文は各フォルダの `00_全文.md` として残置

## 🛠️ 条文の追加・更新（メンテナ向け）

```bash
# 1) e-Gov から条文全文を取得し、BOM付きUTF-8 で保存
#    ファイル名: NN_法令名.md（NN は連番）

# 2) 分割スクリプトを実行（1法令だけ指定）
python3 scripts/laws_splitter.py NN_法令名.md

# 3) 自動生成:
#    - NN_法令名/ （章/節/款/附則に分割）
#    - INDEX.md   （マスターINDEX更新）
```

分割スクリプトは形式A（`## 第X章`）・形式B（行頭 `第X章　…`）・編（`## 第X編`）に対応。
